# Code of Conduct

## Our Standards

- Be respectful.
- Help others learn.
- Welcome constructive feedback.
- Use inclusive language.
- Focus on collaboration.

## Unacceptable Behavior

- Harassment
- Hate speech
- Personal attacks
- Spam
- Trolling

## Enforcement

Project maintainers may remove comments, issues, or pull requests that violate this Code of Conduct.
